# cmux spike revalidation, 2026-10-05 (WP0.4)

Source: `PLAN-final-plan.md` §5 WP0.4, A1, A3, R4 and §8; the cmux CLI at
`/Applications/cmux.app/Contents/Resources/bin/cmux` (0.64.25, build 106) and the documentation that ships with it.
Every command is read-only. No cmux command that selects, focuses, creates or closes anything was run, no
`osascript` was run and no socket was opened by hand. Values here are field names, counts, versions and shapes: no
window titles, session names, project paths, ids or tokens appear. Raw inputs sit under the gitignored
`target/fixture-staging/cmux/`. The decision is `docs/decisions/0025-cmux-join-and-focus.md`; the long form is
`docs/spikes/0003-cmux.md`.

The Claude Code session that ran this spike did not hold `CMUX_SOCKET_CAPABILITY` (checked with
`[ -n "${CMUX_SOCKET_CAPABILITY+x}" ]`; the value was never printed). It is not a descendant of a cmux terminal
either, so a denial below cannot be pinned on the token alone (see row 2).
