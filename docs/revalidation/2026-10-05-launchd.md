# launchd revalidation, 2026-10-05 (WP1.10)

Source: `PLAN-final-plan.md` §5 WP1.10 "Revalidate on macOS 27", A8, A22 and §4.2. The machine runs macOS 27.0.1.
Every command is read-only: `man`, `getconf`, `launchctl print` of a label that is not loaded and `launchctl
getenv PATH`. No `launchctl bootstrap|bootout|kill|load|submit` was run, no plist was written to
`~/Library/LaunchAgents` and `fylgja install launchd --apply` was not run. The uid appears as `<uid>`. The
installer's behaviour is `src/fylgja/cli/install.py`, its plist golden is
`tests/fixtures/launchd/io.github.erik-romson.fylgja.plist`.

What the manuals state is `holds` (the installer is built on it). Behaviour that only a loaded agent shows is
`unknown`, each with the exact command to run by hand after `fylgja install launchd --apply`.
