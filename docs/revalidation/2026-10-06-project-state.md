Source: `PLAN-final-plan.md` §5 WP5.4 ("Revalidate"), §4.7 and A21; `PLAN.md` §4.8. The machine runs gh 2.92.0 and
git on macOS 27. Every probe is read-only (`gh pr view`, `gh api` GET, `gh pr list`, reading the Lidskjalv and draupnir
checkouts). The real responses went to `target/fixture-staging/project/` (gitignored) and only sanitized, renamed

are placeholders. This log holds shapes, field names, counts and versions. The project used for the probes is a
private repository of Erik's organisation (not named here): one project with a closed PR without checks, one with an
open PR with four checks, and a branch with 2,300 workflow runs. The CodexBar and statusline items of WP5.4 belong to a
later step.
