# Application context, second tier: revalidation, 2026-10-06 (WP5.3)

Source: `PLAN-final-plan.md` §5 WP5.3 ("Revalidate"), §4.4 and the cmux decision (`docs/decisions/0025-cmux-join-and-focus.md`,
`docs/spikes/0003-cmux.md`); `research/04-app-activity.md` per-app sections. The machine runs macOS 27.0.1 with Python 3.13.5.
Every probe is read-only: `ls`, and a short `python3` script that parses a file and prints **only key names, types and counts**
(never a path, a title, a project name, an account or a value). `osascript` was not run, nothing was focused, started or written,
and no file under `~/Library/Containers` or `Group Containers` was opened. Values here are field names, counts and versions.

The title formats and A15 markers were revalidated in step 39 (`docs/revalidation/2026-10-06-app-titles.md`). This log covers what
the second tier reads on a focus change.
