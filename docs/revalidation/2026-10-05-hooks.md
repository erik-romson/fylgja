# Revalidation: Claude Code hooks, async semantics, the hook environment and hook cost (WP2.1)

- Date: 2026-10-05
- Installed Claude Code: 2.1.289. Documentation was fetched with `curl` into the gitignored
  `target/fixture-staging/hooks/`: `hooks.md` (250 KB), `cross-session-messaging.md`, `env-vars.md` and
  `statusline.md`, all from `https://code.claude.com/docs/en/`.
