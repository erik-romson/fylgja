# Fylgja

Local daemon that knows where the work is: AeroSpace workspaces and windows, live agent sessions (Claude Code, Codex,
OpenCode, norn), app context, per-workspace todos and a ranked "what next". Backend for Lidskjalv and for a
navigator page.

- `PLAN.md` — the plan outline.
- `research/01-local-findings.md` — what was verified on this machine.
- `research/02-similar-tools.md` — existing tools, what to reuse and what to borrow.
- `research/03-agent-sessions.md` — how to discover Claude Code, Codex and OpenCode sessions and their state.
- `research/04-app-activity.md` — how to tell what is open in Chrome, Teams, JetBrains, Obsidian, iTerm2, and which permissions gate it.
